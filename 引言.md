## 1. Introduction

Text-to-video retrieval (TVR) supports video search and media archive management by locating videos that match a natural-language query. A common design uses an efficient retriever, such as CLIP4Clip (Luo et al., 2022), to shortlist candidates before a more expressive model examines their visual content. Vision–language models (VLMs) can improve this second stage by assessing how closely each candidate matches the query (Ko et al., 2025). In a two-stage system, this creates a decision for each query. The system must decide whether further verification justifies revising the first-stage ranking and incurring the additional inference cost.

Aggregate recall alone provides limited insight into this decision. In a pilot study on MSR-VTT 1K-A, we reranked the top 16 candidates from CLIP4Clip using the VLM's Yes/No scores alone. R@1 increased from 39.60% to 48.30%. The reranker corrected the first result for 188 queries and displaced a correct first result for 101 of the 396 queries initially answered correctly. We refer to the latter changes as *harmful top-1 flips*. This variation motivates a query-level assessment of the benefit, risk and cost of reranking.

A harmful flip can arise when shortlisted videos share visual cues but differ on a specific query constraint. For the query “athletes are getting ready and start running for an event”, the annotated video shows the athletes starting to run, whereas the candidate promoted to first place mainly shows preparations at the starting line. The VLM favoured Yes for both videos and assigned a higher match score to the preparation clip. Both videos show athletes at the starting line. The query requires the reranker to distinguish whether the athletes actually start running. Fine-grained differences in actions and temporal order have also been shown to challenge video–language alignment (Bansal et al., 2024). Kim et al. (2025) examine such differences in a dedicated compositional benchmark.

Prior work has addressed several aspects of VLM-based reranking. BLiM calibrates candidate likelihoods to reduce candidate prior bias (Ko et al., 2025). RankVideo learns relevance judgments through a curriculum that includes pointwise and pairwise supervision (Skow et al., 2026). Adaptive multi-agent retrieval coordinates retrieval, reasoning and query reformulation using feedback from intermediate results (Wu et al., 2025). Query-dependent routing has also been explored in retrieval-augmented generation (Jeong et al., 2024). In two-stage TVR, the routing decision depends on the expected effect of verification on the existing ranking. Retaining a correct first result preserves the top-1 hit. When the first result is wrong, visual evidence may enable a correction. These observations motivate two linked design questions about which part of the query to verify and when a query warrants that additional computation.

We propose a TVR framework that combines calibrated routing with counterfactual verification. Given the query and first-stage score statistics, the router predicts probabilities for three actions in one forward pass. It can accept the first-stage ranking, apply light Yes/No verification, or perform counterfactual verification. It also predicts the query constraint most likely to distinguish close candidates. We calibrate its outputs using temperature scaling (Guo et al., 2017) and use conformal risk control (Angelopoulos et al., 2024) to select an acceptance threshold targeting the expected rate of missed top-1 corrections. For counterfactual verification, we minimally edit the selected constraint and ask a frozen VLM to choose, for a given candidate video, among the original description, its counterfactual alternatives and a “none of the above” option. The probability assigned to the original description serves as the verification score. Comparing “has started running” with “is preparing to run” directly tests the distinction that was decisive in the pilot example.

On a 500-query subset of MSR-VTT 1K-A, the first-stage retriever achieved an R@1 of 38.80%. With the same top-16 candidates and fusion weight, Yes/No verification achieved 45.40% R@1 and counterfactual forced-choice verification achieved 51.00%. The latter reduced harmful top-1 flips from 14 to 7. We evaluate the full framework using recall, directional changes in the top-ranked result and the number of VLM calls per query.

**Contributions**

- We characterise the query-level effects of VLM reranking by measuring top-1 corrections and harmful flips alongside aggregate recall.
- We formulate counterfactual forced-choice verification to assess the query constraint that distinguishes visually similar candidates.
- We develop a calibrated router that selects the level of verification for each query and uses an acceptance threshold calibrated for missed corrections.
