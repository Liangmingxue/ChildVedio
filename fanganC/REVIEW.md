# fanganC 代码审查与验证

## 审查结论

实现完成后启动了两个独立只读审查代理，分别检查数据与特征、训练与评估。两位审查者均未发现 P0/P1 问题。审查指出的四类问题均已修复并通过复查，当前没有阻断首轮后台实验的问题。

| 发现 | 修复 |
|---|---|
| 缓存与训练签名没有完整绑定实时模型和特征来源 | 校验 Qwen3 权重、tokenizer 和库版本；CLIP4Clip 权重、上游 Python 源码、编码库与视频 stat；训练签名包含两个特征 manifest 的签名和文件 SHA256 |
| NaN 查询特征可能绕过重建误差比较 | 发布缓存前校验查询、视频、文本特征的形状与有限性，同时检查误差有限性 |
| 测试路径缓存的分数与 rank 校验弱于训练数据 | 快照时检查分数长度和有限性，按固定 beta 重新计算 light/deep rank；现有 1000 条测试缓存重算不一致数为 0 |
| 首次使用自定义目录时锁文件父目录可能不存在 | 后台脚本显式创建公共锁目录，并通过 Bash 语法检查 |

审查确认：训练标准化和分差先验仅使用 train；候选输入没有 GT、人工 caption 或验证标签；候选 padding 在投影前移除；梯度累积按实际窗口样本数缩放；两个版本开发集选择完成后才评估测试集；测试预算与原分差基线一致。

## 已运行验证

- `python -m compileall -q cvr scripts temp fanganC` 与 `bash -n fanganC/run_background.sh` 通过。
- `python -m unittest discover -s fanganC/tests -v`：8 项通过，覆盖候选与对照行为、padding、概率与重载、标签隔离、快照与 split、预算穷举、优化分组及特征来源签名。
- 项目已有 `temp/stage0_smoke.py` 通过，共 288 次 stub 验证请求。
- 物理 GPU 0 上使用真实 CLIP4Clip 与 Qwen3-4B 的 CUDA smoke 通过：头预热时主干无梯度；联合训练第一步 252 个 LoRA 矩阵、第二步 504 个 LoRA 矩阵有非零梯度；重载后的最大概率差为 0。
- CUDA smoke 的四个真实视频候选分数重建最大绝对误差为 0.0146904；另用 64 条查询、128 个候选核对，视频 batch 8 的最大绝对误差为 0.0081863，低于本实验 0.02 的校验阈值。

详细 CUDA 检查记录位于 `runs/smoke/smoke.json`，检索核对记录位于 `runs/retriever-preflight.json`。它们验证实现可运行，不代表方案 C 已提高测试指标。
